# DeepSeek 聊天记录导入

导入 DeepSeek 导出的聊天记录（JSON / Markdown / TXT / HTML / ZIP），
提取角色人设、世界观和用户重要信息，审核后：

- 给指定 QQ 绑定导入的人设；
- 把生日、喜好、关系、经历写入该用户的长期记忆；
- 只对该 QQ 生效，不影响其他用户。

## 使用

1. 安装插件并启用；
2. 插件详情页 → 导入；
3. 新增记录：选择 QQ、上传导出文件；
4. 等待提取，检查人设和事实；
5. 确认应用，按需开启人设。

## 说明

- 只读取上传的导出文件，不登录 DeepSeek、不抓取网页；
- 普通聊天不会强行生成人设；
- 原始聊天记录不长期保存。
