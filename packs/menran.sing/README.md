# 唱歌（menran.sing）

让机器人真的唱出来：说「唱首歌」就发一条语音，说「唱首小星星」就唱指定那首。

## 怎么用

- 想听歌：`唱首歌`、`来一首`、`想听你唱`
- 点歌：`唱首小星星`、`唱两只老虎`
- 追问：`上次那首再来一遍`（依赖记忆，宿主会自动回填歌名）

## 内容说明

内置三段**公版旋律**（小星星 / 两只老虎 / 生日快乐），用合成音色演奏，
不包含任何受版权保护的录音。想换成真人音色，把 `assets/voice/` 里的文件替换掉即可
（保持文件名不变，或同步改 manifest 里的 `file`）。

## 权限

- 写记忆：只写「我给谁唱过哪首」，不写用户画像；每天最多 5 条
- 不联网、不读插件目录以外的文件
