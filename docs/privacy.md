# 隐私说明

最后更新：2026-10-25

「暖屿 · 小满（Warm Isle）」是一个个人开源的 QQ 陪伴机器人项目，机器人本名就叫小满。
这份说明解释它收集什么、为什么收集、存多久、怎么删。

## 一、收集哪些数据

当你在 QQ 上和机器人聊天时，会保存：

| 数据 | 用途 |
|---|---|
| QQ 号 | 区分不同用户，找到你的聊天记录 |
| 聊天文字 | 生成回复、维持上下文 |
| 图片 | 理解你发的内容（可能含表情包） |
| 语音 | 转写成文字后理解内容；语音文件用于回放 |
| 记忆/事实 | 记住你提过的事，让对话连续 |
| 关系与心情 | 调整称呼、语气、主动消息频率 |

不会收集：通讯录、位置、设备信息、其他 QQ 好友列表。

## 二、数据存在哪

- 存在项目自己的服务器（SQLite 数据库）
- 不卖给第三方，不做广告画像
- 调用模型时，会把当前对话片段发给模型服务商（DeepSeek / 小米 MiMo）用于生成回复和语音
- 搜图时会通过自建的 SearXNG 搜索公开网络图片

## 三、存多久

- 聊天记录：默认长期保留，用于上下文和复盘
- 语音文件：随聊天记录保留
- 删除后立即从数据库移除，无法恢复

## 四、怎么删除自己的数据

在 QQ 里私聊机器人，发送：

```
删除我的数据
```

机器人会先确认一次，再发送：

```
确认删除我的数据
```

确认后会删除：

- 全部聊天记录
- 记忆与事实
- 心情、关系、主动消息状态
- 引导状态、好友画像

删除后机器人会重新认识你。

也可以由管理员在后台调用：

```
DELETE /api/privacy/users/{qqId}
```

## 五、未成年人

本项目为个人项目，不面向未成年人提供服务。如果你是未成年人，请在监护人同意下使用。
